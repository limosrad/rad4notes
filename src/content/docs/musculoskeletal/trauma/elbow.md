## Important fractures and soft tissue injuries

| Name | Description |
| --- | --- |
| Monteggia | Proximal ulnar # + radial head dislocation |
| Galeazzi | Distal radius # + anterior ulna dislocation |
| Essex Lopresti | IO membrane # + distal ulna dislocation + radial head # |
| Tennis elbow | ECRB tendon – lateral epicondylitis |
| Golfer elbow | Common flexor tendon – medial epicondylitis |
| Little leaguer elbow | Medial epicondyle apophysitis |
