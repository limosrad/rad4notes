## Procedure

### Perfusion after stroke intervention

Thrombolysis in cerebral ischaemia (TICI)

| Grade | Angiography finding post-procedure |
| --- | --- |
| 0 | No perfusion beyond occlusion  |
| 1 | Penetration without perfusion beyond occlusion |
| 2a | Partial perfusion; distal branch filling < 50% |
| 2b | Partial perfusion; distal branch filling of &ge; 50% |
| 2c | Near-complete perfusion; visible thrombus absent; delayed contrast runoff present |
| 3 | Full perfusion with visible distal branches |

## Post procedure

### Haemorrhage after intervention

ECASS scoring of haemorrhagic transformation
- Haemorrhagic infarct (HI)
- Parenchymal haematoma (PH)

| Grade | CT finding |
| --- | --- |
| HI1 | Small petechiae |
| HI2 | Medium petechiae |
| PH1 | HI large (≤ 30% of infarcted area; mild mass effect) |
| PH2 | Hematoma (≥ 30% of infarcted area; significant mass effect) |
