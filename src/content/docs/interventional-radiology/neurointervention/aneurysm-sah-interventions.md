## Preprocedure evaluation

### List of endovascular interventions

| Intervention | Pros | Cons |
| --- | --- | --- |
| **Endosaccular filling** |  |  |
| - Simple coiling | Technically simple | Narrow neck required (< 4 mm) |
| - Balloon-assisted coiling | Relatively technically simple | Narrow neck required (< 7 mm) |
| - Stent-assisted coiling | Can be used in wide neck | In stent thrombosis, requires dual antiplatelet therapy |
| - Combined balloon and stent-assisted coiling | - as above | - as above |
| **Flow diversion and vessel wall healing** |  |  |
| - Stent graft (off-label) | Cost effective | Cannot be used in tortuous vessels<br>Can occlude  delicate tiny perforators |
| - Flow diverter | Can be used in wide neck<br>Good patency rates | Requires dual antiplatelet therapy |
| - Parent artery occlusion  | Last resort for giant aneurysms especially in posterior fossa | Requirement of good collateral supply |
| **Combined/hybrid** |  |  |
| - Intra-aneurysmal flow disruptors | Highly specific and targeted towards individual aneurysm | Limited availability<br>Precise sizing required |

## Post procedure management

### Early complications

- Vasospasm 
    - 4-14 days (peak at 1 week)
    - Prophylaxis: IV nimodipine
    - Treatment: IV and intraarterial nimodipine, milrinone
    - Rescue: Mg-sulphate, papaverine, superior cervical ganglion block

### Grading of residual aneurysm filling

Modified Raymond–Roy classification = modified Montreal scale

| Grade | DSA finding |
| --- | --- |
| 1 | No filling |
| 2 | Filling of neck only |
| 3a | Filling within the coil interstices |
| 3b | Filling outside coil interstices, along wall |

- Higher grade has also been shown to provide recanalisation risk
