## Extra-axial haemorrhage

EDH vs SDH

|  | Extradural haematoma | Subdural haematoma |
| --- | --- | --- |
| Location | Between the skull and dura mater | Between the dura and arachnoid mater |
| Cause | Trauma (fracture) | Tear of cortical bridging veins |
| Acute shape | Lenticular biconvex | Crescentic concave |
| Chronic shape | Crescentic | Elliptical |
| Crosses suture lines | No | Yes |
| Crosses a dural reflection | Yes | No |

## Blunt cerebrovascular injury

### Indications for CT angiography in polytrauma

- Multiple criteria: Denver criteria, Memphis criteria, Boston criteria

- Common indications:
    - Le Fort II/III fractures
    - Base of skull fracture especially if involving carotid canal or petrous temporal bone
    - cervical spine fracture especially translation and distraction, foramen transversarium
    - subarachnoid haemorrhage especially in basal cisterns
    - acute stroke on CT
    - clinical examination findings suggestive of vascular injury
        - hemiparesis
        - Horner's syndrome

### Grading of blunt cerebrovascular injury

- Biffl's grading

| Grade | Description | Stenosis % |
| --- | --- | --- |
| I | Intimal injury | < 25 |
| IIa | IMH/dissection | 25-70 |
| IIb | IMH/dissection | > 70 |
| IIIa | Pseudoaneurysm<br>AV fistula (insignificant) | < 70 |
| IIIb | Pseudoaneurysm | > 70 |
| IV | Complete occlusion |  |
| V | Active extravasation<br>AV fistula (significant) |  |
