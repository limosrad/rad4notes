## Spine infections

| | Pyogenic spinal infection | Tuberculosis of spine |
| --- | --- | --- |
| Common site | Lumbar | Thoracic |
| Common pattern | Single site + disc space infection<br>Involvement of two adjacent vertebra | Multilevel involvement and skip lesions<br> Spread along anterior longitudinal ligament |
| Disc abscess | + | - |
| Endplate involvement | + | + |
| Paraspinal abscess | &plusmn; | + |
| STIR | + (vertebral body oedema)| - (cold abscesses) |
| T1 C+ | Diffuse vertebral body enhancement<br> Irregular thick-walled abscesses | Localized enhancement<br>Rim enhancement of thin-walled abscess cavities |
:::
