## Craniocervical junction

### Occipital condyle fractures 
- Anderson and Montesano

| Type | Description | Stability |
| --- | --- | --- |
| I | axial loading with minimal or no fracture displacement | Stable |
| II | skull base fracture extending through the condyle | Stable |
| III | alar ligament avulsion fracture | Unstable |

### Atlas fractures 
- Jefferson, as modified by Gehweiler et al

| Type | Description | Stability |
| --- | --- | --- |
| I | posterior arches | Stable |
| II | anterior arch | Stable |
| III | bilateral posterior arch + any anterior ('burst') | Depends on transverse ligament |
| IV | Lateral mass | Stable |
| V | transverse anterior arch &plusmn; longus colli or atalantoaxial ligament avulsion | Stable |


### Odontoid fractures
- Anderson and D’Alonzo

| Type | Description | Stability |
| --- | --- | --- |
| I | oblique through odontoid tip,  alar ligament avulsion | Stable |
| II | dens-body junction | Unstable |
| III | cancellous portion of the axis body | Heals well with  immobilisation but can cause canal compromise |

### Hangman fractures
Effendi et al, modified by Levine and Edwards

| Type | Description | Stability |
| --- | --- | --- |
| I | hairline fractures, <2-mm translation | Stable |
| II | angulation > 11°, >2-mm translation | Variable, external  immobilisation often used |
| IIa | severe angulation without translation, intact anterior  longitudinal ligament | Angulation can worsen with initial traction |
| III | bilateral facet dislocation | Unstable |

### Atlantoaxial rotatory subluxation and fixation  
- Fielding and Hawkins

| Type | Description | Stability |
| --- | --- | --- |
| I | rotatory fixation in normal physiologic range (<48°–52° left or right), dens acts as a pivot, intact alar and transverse  ligaments |Need for surgery depends on degree of rotation, prognosis improves with early reduction |
| II | transverse ligament injured, center of rotation shifts to lateral mass, anterior displacement of the atlas < 5 mm | Unstable |
| III | transverse and alar ligaments both deficient, similar to II but anterior displacement of the atlas > 5 mm | Unstable |
| IV | deficient odontoid, with posterior displacement of the atlas | Unstable |

    | Intact | 0 |

    | **Neurology** |  |
    | Intact | 0 |

- Guidelines for management:
    | TLICS score | Recommendation |
    | --- | --- |
    | Up to 3 | Conservative |
    | 4 | Depends |
    | 5 or more | Surgery |


### Injury morphology

- Compression: &darr; vertebral body height or disrupted endplate
- Burst: posterior cortex involved
- Flexion-distraction: dissociation in the vertical axis
    - Facet dislocation
    - Facet subluxation (articular surface overlap < 50%)
    - Facet diastasis > 2 mm
    - Posterior disk space widening, angulation >11° 
        - &plusmn; focal kyphotic deformity
- Hyperextension-distraction: extension teardrop fracture
- Rotation
    - Listhesis > 3.5 mm but <50% of caudal vertebral body width
    - Usually unilateral locked facets
- Translation
    - Listhesis > 3.5 mm, usually >50% of caudal  vertebral body width
    - Usually bilateral dislocated facets or pedicle fractures
    - Swischuk line (C1-C3 spinolaminar line): < 2 mm offset of C2 lamina = pseudosubluxation in children

| Flexion teardrop | Extension teardrop |
| --- | --- |
| Posterior disc space widening | Anterior disc space widening |
| C5-6 | C2 |
| Retropulsion common | Retropulsion less common |
| Highly unstable | Stable in flexion |

### Discoligamentous integrity

- Disrupted on CT:
    - Distraction or facet joint dislocation ~ DLC disruption
- Disrupted on MRI:
    - abnormal T2 signal in ligaments with disruption
    - fluid in facet capsules with disruption
- Indeterminate on MRI    
    - oedema in capsule interspinous ligament without clear ligament disruption

## Thoracodorsal spine trauma

### Thoracolumbar injury classification and severity score (TLICS) 

- TLICS

    | Injury | Score |
    | --- | --- |
    | **Morphology** |  |
    |  Compression | 1 |
    | Burst | 2 |
    | Rotation / translation | 3 |
    | Distraction | 4 |
    | **PLC status** |  |
    |  Intact | 0 |
    | Indeterminate | 2 |
    | Involved | 3 |
    | **Neurology** |  |
    | Intact | 0 |
    | Nerve root involvement | 2 |
    |  Complete spinal cord or conus medullaris injury | 2 |
    |  Incomplete spinal cord or conus medullaris injury | 3 |
    |  Cauda equina syndrome | 3 |

- Guidelines for management:
    | TLICS score | Recommendation |
    | --- | --- |
    | Up to 3 | Conservative |
    | 4 | Depends |
    | 5 or more | Surgery |


### Injury morphology

- Compression: &darr; vertebral body height or disrupted endplate
    - &gt;15 degree coronal angulation raises score to 2
- Burst: posterior cortex involved
- Rotation: rotational displacement
- Translation: horizontal displacement
- Distraction: anatomic dissociation along vertical axis
    - through ALL, PLC, or osseous elements


### PLC integrity

- Disrupted on CT:
    - Splayed spinous processes = widened interspinous space
    - Avulsion fracture of contiguous spinous processes
    - Widened facet joints
    - Empty facet joints
    - Perched / dislocated facet joints
    - Vetebral body translation or rotation
- Disrupted on MRI;
    - loss of low signal stripe of supraspinous ligament ot ligamentum flavum
    - fluid in facet capsules with disruption
- Indeterminate on MRI    
    - oedema in capsule or interspinous ligament without clear ligament disruption

### Neurologic deficit

- Assessment of spinal cord injury may be done on MRI
    - Abnormal signal (T2 &uarr; or &darr; depending on haemorrhage)
- CT may be used to give percentage of spinal canal compromise ($a$)
    $$
    a = 1 - \frac{x}{y}
    $$
    where $x$ is midsagittal diameter of canal at level of injury<br>
    and $y$ is mean of midsagittal diameters above and below injury
