## Breast cancer staging

### T staging

| T stage | Feature |
| --- | --- |
| T1 | &le; 2 cm |
| T2 | 2-5 cm |
| T3 | &gt; 5 cm |
| T4a | Chest wall (not pectoralis major alone) |
| T4b | Skin oedema, satellite nodules, ulceration |
| T4c | Both T4a and T4b |
| T4d | Inflammatory breast cancer |

### Clinical N staging

| cN stage | Feature |
| --- | --- |
| N1 | Mobile ipsilateral level I/II |
| N2a | Fixed ipsilateral level I/II |
| N2b | Ipsilateral internal mammary nodes |
| N3a | Ipsilateral level III |
| N3b | Both N2a and N2b |
| N3c | Ipsilateral supraclavicular nodes |
