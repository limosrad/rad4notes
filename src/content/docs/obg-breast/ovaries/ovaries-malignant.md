### Pathology of serous ovarian cancer
:::differentials
Serous vs mucinous ovarian neoplasm

| Serous | Mucinous |
| --- | --- |
| Unilocular (fewer septations) | Multilocular (more septations) |
| Papillary projections common | Papillary projections uncommon |
| 60% benign (cystadenomas) | 80% benign cystadenomas |
| Calcifications (psammoma bodies) | Stained glass appearance and high-density cystic component (mucin) |
:::

### Epithelial ovarian cancer staging

| FIGO stage | Definition |
| --- | --- |
| I | Tumour confined to ovaries/fallopian tubes |
| IA | One ovary/tube; capsule intact; no tumour on surface; negative washings |
| IB | Both ovaries/tubes; capsules intact; no surface tumour; negative washings |
| IC | Limited to ovaries/tubes but surgical spill, capsule rupture, or malignant cells in ascites/washings |
| IC1 | Surgical spill |
| IC2 | Capsule ruptured before surgery or tumour on ovarian/tubal surface |
| IC3 | Malignant cells in ascites or peritoneal washings |
| II | Pelvic extension below pelvic brim and/or primary pelvic peritoneal cancer |
| IIA | Extension/implants on uterus and/or fallopian tubes/ovaries |
| IIB | Extension to other pelvic intraperitoneal tissues |
| III | Peritoneal metastases outside pelvis and/or retroperitoneal lymph-node metastases |
| IIIA1 | Positive retroperitoneal lymph nodes only |
| IIIA1(i) | Nodal metastasis ≤10 mm |
| IIIA1(ii) | Nodal metastasis >10 mm |
| IIIA2 | Microscopic extrapelvic peritoneal involvement ± positive retroperitoneal nodes |
| IIIB | Macroscopic extrapelvic peritoneal metastases ≤2 cm ± nodes |
| IIIC | Macroscopic extrapelvic peritoneal metastases >2 cm ± nodes |
| IV | Distant metastases |
| IVA | Pleural effusion with positive cytology |
| IVB | Parenchymal metastases and/or extra-abdominal metastases, including inguinal lymph nodes |

### Treatment

- I: Cytoreduction ± CT
- II: Cytoreduction + CT
- III: NACT + optimal debulking + CT
- IV: CT ± debulking
