## Grading systems for peripheral arterial disease

### Clinical classifications

- Rutherford's classification for acute limb ischaemia

| Class | Clasification | Description |
| --- | --- | --- |
| I | Viable | No sensory loss; no motor loss |
| IIa | Marginally threatened | Pain, sensory loss, no weakness |
| IIb | Immediately threatened | Pain, sensory loss, mild weakness |
| III | Irreversible (non-viable) | Anaesthesia, paralysis, muscle rigor |

- Fontaine stages of chronic limb ischaemia

| Stage | Clasification | Description |
| --- | --- | --- |
| 1 | Asymptomatic | Asymptomatic but decreased pulses; ABI < 0.9 |
| 2a | Intermittent claudication | > 200 m |
| 2b | Intermittent claudication | < 200 m |
| 3 | Ischemic rest pain |  |
| 4 | Ulceration, gangrene |  |

### Ankle-brachial pressure index

| ABPI | Interpretation |
| --- | --- |
| ≥ 1.3 | Calcified vessels<br>- CKD |
| 0.9-1.3 | Normal |
| < 0.9 | Abnormal |
| 0.4-0.9 | Mild to moderate disease (intermittent claudication) |
| < 0.4 | Critical limb ischaemia |

### TASC classification for lesions seen on imaging

| Type | Stenosis | Occlusion | Management recommendation |
| --- | --- | --- | --- |
| A | &le; 10 cm | &le; 5 cm | Endovascular |
| B | Multiple or calcified &le; 5 cm<br>Single &le; 15 cm | &le; 15 cm | Endovascular |

| D | Popliteal involvement | &gt; 20 cm | Surgery |
