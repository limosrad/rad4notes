## LI-RADS for diagnosis of HCC

### Inclusion criteria

| Includes | Excludes |
| --- | --- |
| adult (&gt; 18 years) patients | paediatric patients |
| cirrhosis | vascular cirrhosis (e.g. Budd Chiari) |
| chronic hepatitis B | congenital hepatic fibrosis |
| current or prior HCC | |

### Step 1: assign a diagnostic algorithm

1. Look for these typical features:

    ![LI-RADS step 1a](/images/flowcharts/li-rads-step-1a.svg)

- LR-M features
    - These features may be seen in liver malignancy apart from HCC (e.g., cholangiocarcinoma)

    | Targetoid | Non-targetoid |
    | --- | --- |
    | Represents peripheral cellular and central fibrous stroma characteristic for cholangiocarcinoma<br>Features: | Infiltrative, or marked diffusion restriction, large central necrosis or other atypical feature |

    ![LI-RADS LR-M](/images/diagrams/li-rads-lr-m.svg)

2. Look for major features:

    ![LI-RADS major features](/images/diagrams/li-rads-lr-major.svg)

3. Based on these major features, assign LR-3, LR-4 or LR-5:

    ![LI-RADS major features](/images/diagrams/li-rads-lr-345.svg)

### Step 2: look for ancillary features

| Favours malignancy in general | Favours HCC in particular | Favours benignity |
| --- | --- | --- |
| US visibility as discrete nodule | Non-enhancing “capsule” | Size stability > 2 yrs |
| Subthreshold growth | Nodule-in-nodule | Size reduction |
| Restricted diffusion | Mosaic architecture | Parallels blood pool |
| Mild-moderate T2 hyperintensity | Blood products in mass | Undistorted vessels |
| Corona enhancement | Fat in mass, more than adjacent liver | Iron in mass, more than liver |
| Fat sparing in solid mass |  | Marked T2 hyperintensity |
| Iron sparing in solid mass |  | Hepatobiliary phase isointensity |
| Transitional phase hypointensity |  |  |
| Hepatobiliary phase hypointensity |  |  |

- If these are present, up grade (upto LR-4) or down grade LR status.

    ![LI-RADS ancillary feature upgradation](/images/flowcharts/li-rads-ancillary.svg)

- Do not apply if contradictory ancillary features are present.

### Step 3: apply tiebreaking rules

- Radiologist's discretion when unsure between two categories (= gut feeling).

    ![LT-RADS tiebraeakers](/images/flowcharts/li-rads-tiebreaker.svg)


### Management recommendations

- Report up to 5 of the most highest category observations

- Recommendations:

    | Category | Recommendation |
    | --- | --- |
    | Negative | Return to surveillance in 6 months |
    | Non-categorisable | Alternative CT/MRI in &le; 3 months |
    | 1 | Return to surveillance in 6 months |
    | 2 | Return to surveillance in 6 months <br> Consider repeat CT/MRI in &le; 3 months |
    | 3 | Repeat or alternate CT/MRI in 3-6 months |
    | 4 | MDT &plusmn; biopsy |
    | 5 | HCC confirmed, MDT for management |
    | M | MDT &plusmn; biopsy |
    | TIV | MDT &plusmn; biopsy |

- LI-RADS malignancy by category

    | Category | % HCC | % Malignancy |
    | --- | --- | --- |
    | 1 | 0 | 0 |
    | 2 | 13 | 14 |
    | 3 | 38 | 40 |
    | 4 | 74 | 80 |
    | 5 | 94 | 97 |
    | M | 36 | 93 |
