## Differential diagnosis of cholangiopathies
:::differentials
|  | IgG4-SC | PSC |
| --- | --- | --- |
| Age | 50-70 | 30-50 |
| M:F | 8:1 | 2:1 |
| Location | CBD > IHBR<br>Intrapancreatic CBD ++ | CBD ~ IHBR |
| Length of stricture | Long (< 4 cm) | Short |
| Wall thickening | ++ | -- |
| Luminal occlusion | -- | ± |
| IHBRD | Mild | Minimal |
| Number of lesions | Few | Many (beading) |
| Liver parenchyma | Normal | Cirrhosis |
| ↑ IgG4 | 80-90% | 10% |
| Rx | Steroids | UDCA, transplant |
| Associations | Type 1 AIP, RPF | UC |
:::
