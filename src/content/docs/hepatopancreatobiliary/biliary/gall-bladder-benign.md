## Mirizzi syndrome

- Csendes classification

| Type | Description |
| --- | ---|
| I | Extrinsic compression of common hepatic duct |
| II | Cholecystocholedochal fistula (< 1/3rd of CHD circimference) |
| III | Cholecystocholedochal fistula (< 2/3rd of CHD circimference) |
| IV | Cholecystocholedochal fistula involving entire CHD wall |
| V | Cholecystoenteric fistula |
