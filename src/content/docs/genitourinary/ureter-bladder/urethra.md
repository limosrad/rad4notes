## Paraurethral / pelvic cysts

:::differentials
Paraurethral cysts
| Midline | Lateral |
| --- | --- |
| Utricle cyst | Seminal vesicle cyst |
| Mullerian cyst | Vas deferens diverticulum |
| Ejaculatory duct cyst |  |
:::

:::differentials
Utricle cyst vs Mullerian cyst

| Utricle cyst | Mullerian cyst |
| --- | --- |
| Pear shaped, small | Tear drop shaped, occasionally large |
| Limited to prostate | Extends beyond prostate |
| Communicates with urethra | No urethral communication |
:::

## Urethral trauma

:::trivia
Urethral injury types (Goldman)

1. Stretching of urethra
2. Membranous urethra &rarr; extraperitoneal contrast **without** perineal contrast
3. Membranous + bulbar urethra &rarr; extraperitoneal contrast **with** perineal contrast
4. Prostatic urethra + bladder base
5. Bulbar urethra &rarr; straddle injuries
:::

## Urethral cancer:

- Prostatic urethra – TCC
- Bulbar urethra – SCC (most common overall)
- Urethral diverticulum – adenocarcinoma
