## Adrenal adenomas

### Quantitative paramters in adrenal adenoma imaging

- Absolute washout (AW) = (portal - delayed) / (portal - non-contrast)
- Relative washout (RW) = (portal - delayed) / portal
- Adrenal signal intensity index (SII) = (in-phase - opposed-phase)/in-phase
- Adrenal spleen ratio (ASR) = (lesion opposed-phase/spleen opposed-phase) / (lesion in-phase/spleen in-phase)

:::differentials
Adrenal lesions on adrenal protocol CT and MRI
| Adenoma | Metastasis | Phaeochromocytoma |
| --- | --- | --- |
| Hypervascular (AW > 60%, RW > 40%)<br>Fat containing (60%) (NCCT < 10 HU, SII > 20%, ASR ≤ 0.7) | ↑ attenuation on NCCT<br>↓ venous phase attenuation → ↓ AW, RW<br>Usually, no fat | Can have fat and is usually hypervascular<br>Calcification, size > 3 cm and heterogeneity can differentiate from adenomas |

* AW = absolute washout, RW = relative washout, ASR = adrenal spleen ratio, SII = signal intensity index
:::

## Bilateral adrenal lesions

:::differentials
| Non-neoplastic | Neoplastic |
| --- | --- |
| Adenomas (sheer prevalence)| Metastasis |
| Haemorrhage | Phaeochromocytomas |
| Granulomatous infection (TB, histoplasmosis) | Lymphomas |
| Adrenal hyperplasia | |

Even in known malignancy, adenoma is more likely than metastasis. Suspect metastasis if:
- size > 4 cm
- rapidly increasing size
:::
