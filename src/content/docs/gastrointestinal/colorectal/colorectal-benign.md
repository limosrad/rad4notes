## Infective enterocolitis

:::differentials
| Infectious agent | Common site |
| --- | --- |
| Giardia | duodenum and proximal jejunum |
| Strongyloides | duodenum and proximal jejunum |
| Salmonella | Ascending colon |
| Shigella | Sigmoid colon |
| Cytomegalovirus | ileocolic (pancolitis) |
| Campylobacter | distal colon |
| Herpes simplex virus | Rectum |
| Gonococcus | rectum |
| Chlamydia trachomatis (LGV) | rectosigmoid |
| Amoebiasis | right colon and caecum |
| Clostridium difficile | pancolitis |
| Yersinia | terminal ileum |
| Actinomycetes | appendix > sigmoid colon with abscesses and fistulae |
| TB | caecum > terminal ileum |

:::

## Colonic volvulus
:::differentials
| Caecal volvulus | Sigmoid volvulus |
| --- | --- |
| Less common | More common |
| Young patients | Old age |
| Predisposing: variant anatomy – caecum is peritoneal (i.e., on the mesentery) | Debilitated or patients with intellectual disability |
| Haustra visible | Haustration lost |
| Remaining large bowel collapsed | Remaining large bowel distended |
| Possible small bowel dilatation (if ileocecal valve incompetent) | Apex of loop above D10 (below diaphragm)Inferior convergence at S1-3 (Frimann Dahl sign)Named signs: liver overlap, left flank and pelvic overlap, coffee bean, bird of prey |
:::
