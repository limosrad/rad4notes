## Vascular closure devices

### Mechanisms

- Active closure devices

| Mechanism | Examples of device |
| --- | --- |
| Suture mediated closure | Perclose ProGlide |
| Nitinol clip | StarClose |
| Arteriotomy tamponade | Catalyst |
| Polyethylene glycol seal | Mynx, Exoseal, Closer |
| Collagen plug | Vascade, AngioSeal |
| Resorbable plug placed during access | FISH |

- Assisted closure devices

| Mechanism | Examples of device |
| --- | --- |
| Pressure assisted | Safeguard, FemoStop, QuicKlamp |
| Radial artery compression | Safeguard Radial, TR Band, RadiStop, RadAR, RADstat |

- Topical haemostasis pads and patches
    - ChitoSeal, CloSur PAD, D-Stat, V+Pad, Syvek patch, SafeSeal

- Hybrid
    - Axera

### Complications

- Intravascular migration and foreign body obstruction
    - Most feared complication
    - Acute limb ischaemia &rarr; surgical embolectomy

- Others
    - Immediate: bleeding, haematoma, delayed bleeding
    - Delayed: infection, scar, pseudoaneurysm, arterial stenosis
